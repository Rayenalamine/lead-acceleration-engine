# Lead Acceleration Portal

Vite + React 18 + TypeScript + Tailwind intake UI with multi-step capture and real-time qualification polling.

## Run

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173` and calls the Spring Boot API at `http://localhost:8080`.

Optional env (`frontend/.env`):

```
VITE_API_BASE_URL=http://localhost:8080
```
